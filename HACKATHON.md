## Selected Problem Statement
**Problem 01: Intelligent Git Conflict Resolution with Testing Provenance**

MergeLens is a Git conflict resolution tool that shows where each side of a conflict came from, whether it was tested, and whether it runs in production. It produces a normal Git commit at the end.
